# SORUMLULUK REDDİ

Bu proje yalnızca eğitim ve kişisel kullanım amacıyla hazırlanmıştır. İçerik barındırmaz veya dağıtmaz; yalnızca kamuya açık kaynaklara ait bağlantı ve listeleme bilgileri sunar. Kullanımından doğabilecek sonuçlardan proje sahibi sorumlu değildir. Kullanıcı, projeyi kendi sorumluluğunda kullanmayı ve yasalara uymayı kabul eder. Telif hakları ilgili sahiplerine aittir; olası ihlallerde doğrudan içerik sahibi veya yayıncı ile iletişime geçilmelidir.
