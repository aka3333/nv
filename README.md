# SORUMLULUK REDDİ

Bu proje yalnızca eğitim ve kişisel kullanım amacıyla hazırlanmıştır. Herhangi bir içerik barındırmaz veya dağıtmaz; yalnızca kamuya açık kaynaklara ait bağlantı ve listeleme bilgileri sunar.

Projenin kullanımından doğabilecek sonuçlardan proje sahibi sorumlu değildir. Kullanıcı, projeyi kendi sorumluluğunda kullanmayı ve yürürlükteki yasalara uymayı kabul eder.

Telif hakları ilgili hak sahiplerine aittir. Olası telif hakkı ihlalleriyle ilgili talepler doğrudan ilgili içerik sahibi veya yayıncıya iletilmelidir.
